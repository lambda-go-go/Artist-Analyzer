# Artist Analyzer

Spotify Web API를 활용하여 음악 아티스트의 인기도, 팔로워 수, 장르 및 대표 트랙 통계를 분석하고 두 아티스트를 비교 분석하는 프로그램입니다.

## 1. 프로젝트 개요
아티스트의 대중적 인지도와 음원 통계를 간편하게 확인하고 비교할 수 있도록 기획했습니다. 

## 2. 주요 기능
- 아티스트 상세 분석: 아티스트 이름 검색을 통해 팔로워 수, 인기도(0~100), 대표 장르 및 상위 인기 트랙 목록을 조회합니다.
- 트랙 통계 집계: 상위 트랙들을 바탕으로 분석 곡 수, 평균 인기도, 평균 재생 시간(분:초)을 계산하고 최고 인기곡을 선별합니다.
- 두 아티스트 지표 비교: 두 아티스트의 핵심 수치를 한눈에 비교할 수 있는 표 형태로 대조 출력합니다.
- 차트 시각화: Matplotlib을 활용하여 4가지 주요 지표(인기도, 팔로워 수, 트랙 평균 인기도, 평균 재생 시간)를 2x2 막대 그래프로 시각화하고 PNG 이미지 파일로 저장합니다.
- 리포트 텍스트 파일 저장: 단일 분석 리포트 및 비교 분석 결과를 깔끔하게 정돈된 txt 파일로 저장할 수 있습니다.
- 안정적인 예외 처리: 잘못된 아티스트명이나 오타 입력 시 프로그램이 비정상 종료되지 않고 안내 메시지를 출력하며 재입력을 유도합니다.

## 3. 파이썬 버전
Python 3.10 이상

## 4. API Key 설정 (.env)
Spotify API 접근에 필요한 Client ID와 Client Secret은 .env을 통해 저장합니다.

## ５. .env 파일 형식
프로젝트 최상위 디렉토리에 .env 파일을 생성하고 아래 형식으로 키를 입력합니다.

SPOTIFY_CLIENT_ID=your_spotify_client_id_here
SPOTIFY_CLIENT_SECRET=your_spotify_client_secret_here

- 따옴표 없이 키 값을 그대로 입력합니다.

## 6. 프로젝트 구조 및 코드 설계
3개의 모듈로 분리하여 설계했습니다.
main.py               # 프로그램 진입점 및 CLI 메뉴 제어
spotify_api.py        # Spotify API 인증, 데이터 수집 및 통계 산출
visualizer.py         # 텍스트 리포트 생성 및 Matplotlib 차트 시각화

### 모듈별 세부 설명
- main.py:
  - 전체 사용자 상호작용을 제어하는 진입점입니다.
  - 프로그램 구동 시 API 연결을 확인하고, 메뉴 선택(단일 분석, 비교 분석, 자격 증명 재설정, 종료)에 따른 흐름을 제어합니다.
  - 사용자 입력 오류, 빈 입력, KeyboardInterrupt 등의 예외를 처리하여 프로그램이 안정적으로 유지되도록 구현했습니다.

- spotify_api.py:
  - SpotifyClient: Client Credentials Flow를 이용해 액세스 토큰을 자동 발급받고 만료 시간을 계산하여 유효한 인증 상태를 유지합니다.
  - 최신 Spotify Web API 정책(2024년 11월 이후 개발자 모드 앱의 상위 트랙 조회 403 제한 및 지표 마스킹)에 대응하여, 공식 검색 API와 플랫폼 메타데이터를 결합한 하이브리드 수집 로직을 적용했습니다. 이를 통해 신규 등록된 개발자 계정에서도 팔로워 수, 인기도, 상위 트랙 및 재생 시간을 누락 없이 안정적으로 수집합니다.

- visualizer.py:
  - build_artist_report / build_comparison_report: 수집된 데이터를 가독성 높은 텍스트 표 형식으로 포맷팅합니다.
  - render_comparison_charts: OS별 한글 폰트를 자동 감지하여 글자 깨짐을 방지하고, 2x2 서브플롯 막대 차트를 생성하여 화면 표시 및 PNG 파일 저장을 수행합니다.

## 7. 프로그램 이용
프로그램 실행 시 api인증을 합니다. .env파일을 생성시 자동 처리됩니다.
-  아티스트 상세 분석 및 리포트
  아티스트 입력 시 주요 지표 분석 리포트를 출력합니다.
- 두 아티스트 주요 지표 전격 비교 (시각화 그래프)
  비교할 두 아티스트를 입력 시 리포트를 출력하고 그래프로 시각화합니다.
- Spotify API 자격 증명 재설정
  api 변경 시 사용합니다.
- 프로그램 종료
  프로그램을 종료합니다.
